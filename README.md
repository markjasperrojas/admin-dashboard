# Admin Dashboard

A mini portfolio-style website built from scratch as part of [The Odin Project](https://www.theodinproject.com/) curriculum. This static frontend project focuses on layout, design, and visual presentation rather than application functionality. It was my most challenging design project at that time and gave me an opportunity to strengthen my CSS skills, particularly with Grid and Flexbox. The website is not yet responsive.

All of the icons and more can be downloaded as SVGs from [Material Design Icons](https://pictogrammers.com/library/mdi/).

**Logo**: paint palette school supply Free PNG by [Vecteezy](https://www.vecteezy.com/png/24089512-paint-palette-school-supply).
